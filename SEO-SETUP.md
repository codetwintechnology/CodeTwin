# CodeTwin Technology SEO setup

This package preserves the existing black/red CodeTwin theme and adds technical/content SEO.

## Before publishing
1. Replace `https://YOUR-DOMAIN-HERE.com` in `sitemap.xml`, `robots.txt`, canonical URLs and JSON-LD with the real production domain. The site domain was not supplied, so it is intentionally not guessed.
2. In Google Search Console, add the real domain/property, complete verification, then submit `/sitemap.xml`. Google recommends submitting a sitemap and using URL Inspection after structured-data deployment.
3. Add your Google Analytics 4 Measurement ID to the pages. No ID was supplied, so no fake tracking ID was inserted.
4. Validate structured data with Google's Rich Results Test and inspect the live URLs after deployment.

## Location
All local SEO wording uses **Rajkot, Gujarat**, not Surat.
